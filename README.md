
# 💰 Personal Finance Analytics Dashboard

A personal finance dashboard built using Python, Streamlit, Pandas, and Plotly. It helps users understand their income, expenses, savings, and monthly spending patterns through interactive charts and financial summaries.

## 🚀 Features

- Upload your own financial data using CSV files.
- Automatically clean and process transaction data.
- Calculate total income, expenses, and net savings.
- Calculate monthly savings rate.
- Filter transactions by month.
- Identify top spending categories.
- Visualize income vs expenses.
- Track monthly savings trends.
- View expense breakdowns using interactive charts.
- Download filtered transaction data as CSV.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Itz-https/personal-finance-analytics.git
```

### 2. Open the project folder

```bash
cd personal-finance-analytics
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

## 📊 How to Use

1. Open the dashboard.
2. Upload a CSV file containing your transactions.
3. Make sure your CSV includes these columns:

| Column | Description |
|---|---|
| Date | Transaction date |
| Type | Income or Expense |
| Category | Transaction category |
| Amount | Transaction amount |

4. Select a month to analyse your finances.
5. Explore the charts and financial summaries.
6. Download your filtered transaction data if needed.

## 🎯 Project Objective

The objective of this project is to use Python and data visualization tools to turn raw financial transaction data into meaningful insights, helping users better understand their spending habits and savings.
