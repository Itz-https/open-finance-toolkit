# Security Policy

## Supported versions

Only the latest released version receives fixes.

## Reporting a vulnerability

Please do **not** report security problems in a public issue.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which version you used. Never include real financial data.

You can expect an acknowledgement within a few days. We will keep you updated, fix confirmed problems as quickly as we reasonably can, and credit you in the changelog if you wish.

## What this project handles

Open Finance Toolkit processes financial files on your own computer. It makes no network calls and stores nothing. Problems we especially want to hear about include crashes or unsafe behaviour caused by a crafted CSV file, and any accidental data leak.
